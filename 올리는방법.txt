편한손 창업 모집 페이지 올리는 방법
주소: https://pyeonhanson.co.kr/partners/

1. config.php 를 메모장으로 열어 아래 4가지를 바꿉니다.
   - DB_USER / DB_PASS / DB_NAME : 기존 pyeonhanson.co.kr 사이트가 쓰는 DB 정보 그대로
     (기존 사이트의 설정 파일이나 호스팅 관리자 페이지에서 확인)
   - ADMIN_PASS : 지원자 관리 화면 비밀번호 (새로 정하세요)
   - NOTIFY_EMAIL : 지원서 알림 받을 이메일 (선택)
   ※ 저장할 때 인코딩은 UTF-8 로 저장하세요.

2. FTP로 접속해서 웹 루트(기존 index 파일이 있는 곳, 보통 public_html 또는 www)에
   partners 폴더를 만들고, 이 폴더 안의 파일을 전부 올립니다.
   index.html, apply.php, admin.php, config.php, install.php, .htaccess
   (.htaccess 는 점으로 시작하는 숨김 파일이라 FTP 프로그램에서 숨김 파일 보기를 켜야 보입니다.)

3. 브라우저에서 한 번 실행합니다.
   https://pyeonhanson.co.kr/partners/install.php
   "설치 완료"가 뜨면 FTP에서 install.php 를 지웁니다.

4. 확인
   - 모집 페이지: https://pyeonhanson.co.kr/partners/
   - 지원서를 하나 테스트로 넣어보고
   - 관리자 화면: https://pyeonhanson.co.kr/partners/admin.php 에서 들어온 것 확인 후 삭제

5. 기존 홈페이지 메인에 "편한손 창업 모집" 링크(/partners/)를 하나 걸어주면
   구글·네이버가 페이지를 더 빨리 찾습니다.
   네이버 서치어드바이저에서 https://pyeonhanson.co.kr/partners/ 수집 요청도 해주세요.

※ Cloudflare 캐시 때문에 수정한 내용이 바로 안 보이면
   Cloudflare 관리 화면에서 캐시 삭제(Purge) 하면 됩니다.
